# User Intake Form

Collect this information before filling the master fact base.

## How To Use This File

Use this file as the source checklist when the user does not already have a complete resume, or as a gap-check when the user provides an existing resume PDF, Word/DOCX file, screenshot, image, Figma reference, or HTML/CSS template.

The user can either fill this file directly or paste rough notes into a Codex thread. Convert only confirmed facts into `master/master-data/`; do not invent missing dates, titles, tools, metrics, or outcomes.

Before the first tailoring task, make sure the workspace has:

- A fact source: existing resume, completed intake answers, or pasted work history.
- A template choice: built-in ATS-friendly template or custom template.
- A page target for the resume and cover letter.
- A decision about ATS risk if the preferred template is visually complex.
