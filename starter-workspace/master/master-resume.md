# Candidate Master Resume

This file is the private source-of-truth entry point for a user's resume facts.
Keep the public starter copy generic. After copying the starter workspace into a
private folder, replace these placeholders with verified personal facts.

## How To Use

1. Complete `master-data/profile.md`.
2. Add verified project, experience, education, certification, and skills facts.
3. Use `master-data/evidence-map.md` as the fast lookup layer for target roles.
4. Never invent facts when tailoring a target resume.

## Suggested Modules

| File | Purpose |
| --- | --- |
| `master-data/profile.md` | Candidate identity, contact details, location, authorization, target roles, and summary themes. |
| `master-data/skills.md` | Verified skills, tools, methods, and supported proficiency notes. |
| `master-data/evidence-map.md` | Role requirement to evidence mapping. |
| `master-data/education-certification.md` | Education, certifications, awards, and training. |
| `master-data/projects/featured-project.md` | Detailed source facts for a strong portfolio or product project. |
| `master-data/experience/current-role.md` | Most recent or most relevant role. |
| `master-data/experience/previous-role.md` | Earlier role with transferable evidence. |
| `master-data/experience/additional-background.md` | Optional older or adjacent experience. |
| `master-data/career-story.md` | Optional narrative bridge for career transitions. |

## Privacy Reminder

This public starter file must not contain real personal details, private company
information, unpublished application materials, or target-job notes.
