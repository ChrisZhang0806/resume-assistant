# Master Data Index

This directory is the modular source-of-truth for tailoring target resumes.
The public starter copy uses placeholders only. Replace the placeholders after
copying the workspace into a private folder.

## Core Files

| File | Use |
| --- | --- |
| `profile.md` | Candidate identity, contact, location, authorization, target roles, and summary themes. |
| `skills.md` | Verified skills, tools, methods, and proficiency notes. |
| `evidence-map.md` | Fast mapping from job requirements to supported evidence. |
| `education-certification.md` | Education, certifications, training, awards, and relevant coursework. |
| `career-story.md` | Optional career narrative and positioning notes. |

## Detailed Evidence Modules

| File | Use |
| --- | --- |
| `projects/featured-project.md` | Strong project or portfolio case study facts. |
| `experience/current-role.md` | Current or most recent role facts. |
| `experience/previous-role.md` | Earlier role facts. |
| `experience/additional-background.md` | Optional older or adjacent background facts. |

## Loading Guidance

- Read `profile.md` and `evidence-map.md` before tailoring a resume.
- Load only the detailed modules needed for the target role.
- Use only verified facts from these files or user-confirmed additions.
- If evidence is missing, mark it as a gap instead of inventing it.
